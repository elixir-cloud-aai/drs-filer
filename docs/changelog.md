# Changelog

Changes of each release are listed in the [release notes on
GitHub](https://github.com/elixir-cloud-aai/drs-filer/releases), which are
published from the notes in `docs/releases/` where these exist, followed by
GitHub's generated list of changes (see [Versioning and
releases](development.md#versioning-and-releases)); each release with notes
is listed here, newest first. No release of the current code base has been
published yet.

How to upgrade existing deployments is described in
[Upgrading](upgrading.md).
